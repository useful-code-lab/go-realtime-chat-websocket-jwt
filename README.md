# Real-Time Go Chat — WebSocket, JWT & PostgreSQL

Практический пример backend-приложения на Go, который показывает, как построить **чат в реальном времени с авторизацией, WebSocket, приватными сообщениями, PostgreSQL и тестами**.

Проект можно использовать не только как готовое приложение, но и как **учебную основу для изучения архитектуры Go backend-приложений**. Здесь можно посмотреть, как организовать WebSocket-соединения, JWT-аутентификацию, работу с пользователями, комнатами, сообщениями, базой данных и миграциями.

## 🎯 Что вы получите из этого проекта

Этот репозиторий будет полезен разработчику, который хочет увидеть не отдельный пример WebSocket или JWT, а их взаимодействие в одном небольшом приложении.

Из проекта можно взять готовые практические решения для:

* создания WebSocket-сервера на Go;
* организации чата с сообщениями в реальном времени;
* работы с несколькими комнатами;
* отправки публичных и приватных сообщений;
* авторизации пользователей через JWT;
* хранения JWT в cookie;
* разделения HTTP- и WebSocket-логики;
* организации пользователей, клиентов, комнат и Hub;
* подключения PostgreSQL;
* управления схемой БД через миграции;
* загрузки пользовательских аватаров;
* написания unit- и integration-тестов;
* автоматического запуска проверок через GitHub Actions.

## 🚀 Что можно изучить на практике

### WebSocket и real-time коммуникация

Проект показывает, как организовать двустороннее соединение между браузером и Go-сервером с использованием WebSocket.

Можно изучить:

* установку WebSocket-соединения;
* подключение и отключение клиентов;
* передачу JSON-сообщений;
* broadcast сообщений;
* работу комнат;
* отправку сообщений конкретному пользователю;
* управление несколькими клиентами одновременно.

Основная логика чата разделена на `Hub`, `Room` и `Client`, поэтому код можно использовать как пример организации real-time части backend-приложения.

### JWT-аутентификация

В проекте реализован полноценный сценарий регистрации и авторизации пользователя.

JWT используется для идентификации пользователя, а токен сохраняется в cookie.

Это позволяет посмотреть на практическую связку:

**регистрация → логин → JWT → cookie → middleware → WebSocket**

и понять, как авторизация пользователя может быть связана с real-time соединением.

### PostgreSQL и миграции

Проект содержит поддержку PostgreSQL и SQL-миграций.

Можно посмотреть:

* структуру таблиц;
* создание и откат миграций;
* подключение базы данных;
* разделение модели хранения данных и бизнес-логики;
* организацию конфигурации приложения.

Для миграций используется `golang-migrate`.

### Тестирование Go backend

В репозитории присутствуют unit- и integration-тесты для основных компонентов.

В качестве примера можно посмотреть, как тестировать:

* пользовательскую логику;
* WebSocket и HTTP handlers;
* отдельные компоненты чата;
* HTTP-запросы через `httptest`.

Интерфейсы в части chat-логики позволяют изолировать зависимости и сделать код удобнее для тестирования.

### GitHub Actions

Проект содержит GitHub Actions для автоматической проверки изменений.

Это позволяет увидеть базовый вариант CI для Go-проекта:

**push → проверка → тесты → сборка**

и использовать конфигурацию как основу для собственного backend-репозитория.

## 🏗 Архитектура

Основная логика приложения разделена на несколько частей:

```text
cmd/server
    ↓
app
    ├── auth
    ├── user
    ├── web
    └── chat
          ├── Hub
          ├── Room
          └── Client
    ↓
PostgreSQL
```

### Основные компоненты

**`auth`**

Работа с JWT и аутентификацией.

**`user`**

Регистрация, авторизация и работа с пользователями.

**`web`**

HTTP handlers, middleware и WebSocket endpoint.

**`chat`**

Основная real-time логика: клиенты, комнаты и Hub.

**`migrations`**

SQL-миграции базы данных.

## ⚙️ Запуск проекта

### 1. Клонирование

```bash
git clone https://github.com/go-portfolio/go-realtime-chat-websocket-jwt.git
cd go-realtime-chat-websocket-jwt
```

### 2. Установка зависимостей

```bash
go mod download
```

### 3. Настройка окружения

Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

Укажите необходимые параметры подключения к PostgreSQL.

### 4. Установка migrate

```bash
go install github.com/golang-migrate/migrate/v4/cmd/migrate@latest
```

Проверьте установку:

```bash
migrate -version
```

### 5. Применение миграций

```bash
make migrate-up
```

Для отката последней миграции:

```bash
make migrate-down
```

### 6. Запуск

```bash
go run cmd/server/main.go
```

После запуска приложение доступно по адресу:

```text
http://localhost:8080
```
